# 公路车训练教练

在个人微信单聊里问「今天骑什么」，临时调整课表，骑完回报主观用力程度。课前提醒会读取调整后的课程，课后询问会读取当天的完成情况。首版针对一位骑手与一条独立微信绑定，使用 SQLite 保存档案、调课、反馈和提醒任务。

已在腾讯云 Lighthouse 的独立 Hermes Profile 上通过微信扫码、入站回复和重启后的定时推送。手机确认收到一条在会话约 7 小时 27 分钟未互动后发出的定时提醒。完整结果见[验收记录](docs/acceptance.md)。

## 本地启动

安装 Node.js 24。在仓库根目录运行，无需安装 npm 依赖。

```sh
npm test
npm run demo
npm start
```

`demo` 使用 [虚构骑手数据](examples/demo.json) 和可控的模拟时钟。交互模式默认将模拟档案写入 `data/coach.sqlite`，运行期间会输出到点的提醒。输入「测试提醒 1 分钟」，保持终端开启，期间无需输入其他内容。在另一个终端执行 `npm start -- jobs` 查看任务。

## 网页训练台

运行 `node src/web.mjs --demo` 后访问 `http://127.0.0.1:18797`。训练台支持骑行与恢复图表、两周课表、网页聊天，以及 FIT、功率 CSV、Intervals.icu API 与活动列表 CSV 导入。真实部署需要独立网站密码，可开启与该教练微信会话的双向同步。 [网站访问、部署与同步指南](docs/web-dashboard.md)

## 微信指令

| 想做什么 | 可以这样说 |
| --- | --- |
| 初次设置 | 周二、周四、周六可骑，想提高爬坡能力 |
| 设置时长与偏好 | 周四 60 分钟 室内 / 每次 75 分钟 / 偏好 户外 |
| 设定功率目标 | FTP 240 功率计测试 / 清除 FTP / 确认 |
| 查看课程 | 档案 / 这周怎么练 / 今天骑什么 / 最近骑行 |
| 临时调整 | 昨晚没睡好，今天只有 45 分钟 / 睡眠 6.5 小时 / 腿部疲劳 6 / 昨天骑太狠 |
| 整周调课 | 周六没空 / 确认 / 取消 |
| 录入完成和历史 | 骑完了，RPE 4 / 最后一组没完成 / 今天改休息 / 记录骑行 昨天 50 分钟 RPE 5 |
| 查询导入数据 | 导入活动 / 功率曲线 |
| 设置提醒 | 开启课前提醒 07:30 / 开启课后提醒 20:30 / 课前提醒改到 08:00 / 暂停提醒 / 提醒状态 |
| 验收投递 | 测试提醒 3 分钟 / 确认收到 123 |

初次设置按每个可骑日 60 分钟起步。此后，修改周安排、目标或 FTP 时会预览改动，确认窗口为 30 分钟。单次调课只作用于当天。每个骑行日保存一份手动摘要，可补填实际时长和 RPE。RPE 用 0–10 的主观用力程度表示。

## 训练规则与数据

- 周计划在可骑日安排耐力课，时长允许时安排一个重点课。基础爬坡偏甜区，长坡或阈值目标偏阈值，短坡或 VO₂max 目标偏 VO₂max。当天先结合近七天手动骑行、疲劳、睡眠和可用时间调整课型，再生成热身、主课、需要时的组间恢复和冷身。全部阶段之和受当天时长硬上限约束。
- FTP 有值时显示功率区间和 RPE。只有手动反馈时只依赖已填写或导入的真实字段，实际骑行时长缺失就留空。规则会简述推荐依据，包括数据缺失情况。档案的室内外偏好会显示在今日课表里。
- 可选模型配置见 [环境变量样例](.env.example)。模型用来理解规则未识别的指令，或解释已经确定的调整。规则校验字段，并生成全部课程数字。配置后，无法识别的当前消息可能会发送到自选 HTTPS 服务，调整说明只发送规则生成的改动标签；档案、历史和微信标识由本地服务保管。缺密钥或模型返回错误时可继续用表中的基础指令。
- 源码中，`src/hermes.mjs` 和 `src/openclaw.mjs` 分别接入微信网关，`src/reminders.mjs` 持久化提醒流程，`src/coach.mjs` 和 `src/training.mjs` 负责训练。间歇规则与聊天传输可独立运行。

## 活动和室内课文件

支持命令行导入 FIT 活动和功率曲线 CSV、从 Intervals.icu 只读同步活动，以及把今日功率课导出为 `.zwo`。从 Strava 导出的原始 FIT 可使用同一入口。每项数据来源、支持字段、FTP 估算条件和操作示例见[骑行数据指南](docs/training-data.md)。
